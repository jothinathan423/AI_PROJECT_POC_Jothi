1. Overview

This application automates the analysis of civil engineering RFQ (Request for Quotation) packages. It reads your documents, runs AI analysis across multiple stages, checks historical bid data for viability, collects human approvals at key gates, and produces a draft proposal — all in one workflow.

2. Opening the Application

Open your browser and navigate to http://localhost:5173. You will see the main pipeline screen with the two pre-loaded documents shown at the top.

📌 The two document cards at the top show the RFQ package (DOCX) and Engineering Drawings (PDF) that have been pre-loaded for analysis. File name and size are shown for each.

3. The Timeline

The horizontal row of numbered circles is the pipeline timeline. Each circle represents one step.

  • Grey circle — step has not run yet (pending)
  • Blue pulsing circle — step is currently running
  • Amber pulsing circle — step is waiting for your decision (gate)
  • Green circle with ✓ — step completed successfully
  • Red circle with ✗ — step was declined or returned

Click any circle to view that step's extracted data or status in the panel below.

4. Starting the Analysis

Click the ▶ Start Analysis button in the top-right corner. The pipeline will begin immediately.

✅ The first two steps (Intake and Quality Gate) run automatically in under a second. The AI steps (3–6) each take 15–60 seconds while calling OpenAI GPT-4o.

5. Reading AI Results

As each AI step completes, its circle turns green and the content panel updates. Click a completed circle to review the extracted data.

RFQ Document Analysis (Step 3)

Shows all fields extracted from the RFQ document: project name, client, location, submission deadline, disciplines required, key deliverables, evaluation criteria and mandatory requirements.

Drawing Register (Step 4)

Lists every drawing sheet found: sheet ID, title, discipline (Civil / Structural / etc.), revision, scale, confidence level, and AI observations. Each field is flagged as read from drawing, AI inferred, or not available.

Cross-Document Analysis (Step 5)

Shows the RFI (Request for Information) register — gaps and conflicts between the RFQ requirements and the drawing package. Each RFI has a priority (High / Medium / Low) and a suggested action.

Bid Viability Assessment (Step 6)

Compares the current project against 10 historical AB Consultants projects. Shows:

  • Technical Match Score — 0–100% bar chart
  • RFI Risk Level — Low / Medium / High based on the number and severity of RFIs
  • Overall Recommendation — Pursue / Pursue with Conditions / Do Not Pursue
  • Top 3 Similar Past Projects — with outcome and profit margin
  • Key Risks and Strengths

6. Human Gate Decisions

When a gate step is reached, the circle turns amber and pulses. Click it to see the decision panel.

Gate 7 — Bid Go / No-Go

The manager reviews the Bid Viability Assessment and decides whether to pursue the bid.

✓ Go — Pursue Bid ✗ No-Go — Decline
⚠️ If you click No-Go — Decline, the pipeline stops. The proposal is not assembled. This is recorded in the audit log.

Gate 8 — Engineering Validation

The engineering discipline lead reviews the AI drawing findings and validates the analysis before proposal writing begins.

Gates 10 & 11 — Commercial Review / Final QA

The proposal manager and an authorised approver review the assembled proposal for coverage, fees, and mandatory compliance sections.

📌 All gate decisions (approve / return, role, timestamp, comment) are saved to the approval_log database table as a permanent audit trail.

7. Completed Pipeline

When all 12 steps complete, every circle turns green and the status bar shows Complete — Ready for Export.

8. Downloading the Proposal

Click the Export circle (12) or navigate to it. Click Download Proposal DOCX to save the AI-generated proposal draft as a Word document.

⚠️ The proposal is an AI-assisted draft. Section 8 (Fee Proposal) is intentionally left blank — fees must be set by an authorised AB Consultants commercial representative before the document is submitted.

10. Troubleshooting

ProblemSolution
Page shows "Loading…" for documentsBackend is not running. Start it: uvicorn main:app --port 8001 --reload
Analysis doesn't startCheck the backend terminal for errors. Ensure .env has a valid OpenAI API key.
Bid Viability shows no similar projectsRun python seed_past_projects.py in the backend folder to populate historical data.
Gate button doesn't respondRefresh and restart the pipeline. Check for multiple Python processes on port 8001 (see README).
DOCX download failsEnsure the pipeline ran to completion through all gates (all circles green).
